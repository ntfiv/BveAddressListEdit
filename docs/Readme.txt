----------------------------------
　BVE AddressList Edit

　かんたんのゆめ　NT/fiv
----------------------------------

BVE Trainsim 5 / 6 のシナリオ選択画面に出るフォルダの履歴を整理するツールです。
履歴の追加、並べ替え、PCに存在しないフォルダの一括削除ができます。

■ 動作環境
  Windows 10 / 11（.NET Framework 4.8）
  インストール不要です。BveAddressListEdit.exe をダブルクリックすると起動します。

■ 使い方
  1. BVE を終了してから、このツールを起動します。
  2. 画面上部の「対象」で BVE5 / BVE6 を選びます。
  3. 履歴を整理します。
     ・追加 …… 「追加...」でフォルダを選ぶと一番上に追加されます（複数選択可）。
                 エクスプローラーからリストにドラッグ＆ドロップしても追加できます。
     ・並べ替え … 「一番上へ／上へ／下へ／一番下へ」、または行をドラッグして移動します。
     ・存在しないフォルダを削除 …… 赤字のフォルダ（PCに見つからないもの）をまとめて消します。
     ・削除 …… 選んだ行を消します（Deleteキーでも可）。
  4. 「保存」（Ctrl+S）で BVE の設定ファイルに書き込みます。

  行のダブルクリックでフォルダを開けます。
  「読み込み直す」（F5）で保存前の変更を取り消せます。

■ 設定ファイルが見つからないとき
  いつもの場所（ドキュメント\BveTs\Settings）に設定ファイルがないと、
  起動時に PC 内から探すか確認します。画面上部の「設定ファイルを探す...」からも探せます。
  見つかったものから使うファイルを選んでください（検索の途中でも選べます）。
  選んだ場所は次回からも使います（%APPDATA%\BveAddressListEdit\paths.txt に記録）。

■ 注意
  ・BVE は終了時に設定を書き戻すため、BVE を閉じてから保存してください。
  ・保存するとき、直前の設定ファイルを .bak として残します。
      ドキュメント\BveTs\Settings\Preferences.xml.bak（BVE5）
      ドキュメント\BveTs\Settings\BveTs6.Preferences.xml.bak（BVE6）
    困ったときは .bak の名前から「.bak」を取ると元に戻せます。
  ・外付けドライブ等が外れているだけのフォルダも「見つからない」と表示されます。
